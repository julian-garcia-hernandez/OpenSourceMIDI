# OpenSourceMIDI

## Purpose
This goal of this app is to help you learn how to play and recognize chords in music.

## How To Build And Run
### Requirements
1. Have flutter framework installed on your system.
2. Have VSCode installed on your system.

### How to Build
1. Open VSCode.
2. Open the root directory of the project.
3. Click the run debug button in the top right.
   
I run it on macOS using VS Code. If you can't please feel free to drop an issue so that I may help you with getting the project to run.

## Why Flutter?
I built this project with the intention to make it as available as possible to everyone. That's why I chose Flutter, because of its ability to target pretty much every mainstream platform. OpensourceMIDI will eventually be compatible with The Web, iOS, Android, macOS, Windows, and Linux.
